# PskovKrom — Псковский Кром в Unreal Engine 5.8

Реконструкция Псковского Крома, Довмонтова города и окрестностей в радиусе километра: рельеф по спутниковой модели, здания и дороги по OpenStreetMap, башни, храмы и заметные дома — по фото и источникам. Проект любительский, некоммерческий: чтобы псковичам было интересно посмотреть на свой город с высоты и пройтись по нему.

**Веб-версия** (three.js, полёт и ходьба, без установки): https://dementev-dev.github.io/PskovKrom/

![Кром с Великой](https://dementev-dev.github.io/PskovKrom/shots/oblique.jpg)

## Что в репозитории

| Папка | Что |
|---|---|
| `scripts/` | генераторы: рельеф, дороги, деревья, застройка, герои (Blender), сцена UE, веб-экспорт; каталог и порядок сборки — `scripts/README.md` |
| `docs/` | цели, дорожная карта, состояние, журнал решений, источники и факты, идеи, сессии |
| `refs/` | исходные данные: выгрузка OSM, модель рельефа, покрытие земли, текстуры, фото с манифестом |
| `web/` | просмотрщик веб-версии; сцену в `build/web/` собирает `scripts/web_export.py` |
| `Krom/` | скелет проекта UE: уровень, Landscape, настройки. Ассеты не хранятся — их строят скрипты |
| `media/progress/` | кадры и ролики по ходу работы |

Сгенерированные ассеты UE и промежуточные файлы (`build/`) в репозитории отсутствуют: свежий клон собирается по `scripts/README.md`, раздел «Первичная сборка» (UE 5.8, Blender 5.2, Python 3 с `scripts/requirements.txt`).

## Как это делалось

Всё повторяемое — скриптами; руками в редакторе создаётся только Landscape. Работа велась с агентами Claude Code: правила для них — `AGENTS.md`, словарь — `CONTEXT.md`, решения — `docs/DECISIONS.md`. Исторические утверждения и размеры — со ссылкой на источник в `docs/REFERENCES.md` или с пометкой «гипотеза».
