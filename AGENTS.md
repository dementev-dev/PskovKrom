# AGENTS.md — точка входа для любого агента

**PskovKrom** — Псковский Кром и Довмонтов город в Unreal Engine 5.8. Владелец — Дмитрий; цель — удовольствие и «вау» у псковичей, не коммерция.

## Начало сессии

Главный агент читает по порядку; субагент — то, что названо в задании.

1. `docs/STATE.md` — где мы сейчас.
2. `CONTEXT.md` — словарь: его словами пишем документы, код и ответы владельцу.
3. Последний файл в `docs/handoff/` — на чём остановились.
4. `docs/ROADMAP.md` — текущая веха и её критерии готовности.
5. `docs/GOALS.md` — когда задача касается масштаба, стиля или эпохи.
6. `docs/DECISIONS.md` — перед тем как предлагать то, что уже могли решить.

Готово, когда владелец получил одну фразу: текущая веха и предложенный фокус сессии. Дальше — одна задача вехи за раз; идея вне текущей вехи — строкой в `docs/IDEAS.md`, а работа остаётся в вехе.

## Документы

| Файл | Что туда | Как меняется |
|---|---|---|
| `CONTEXT.md` | термины и слова, которых избегаем | новый термин — сразу, как устоялся; смысл старого — только с владельцем |
| `docs/GOALS.md` | видение, scope, non-goals, принципы | только через запись в DECISIONS |
| `docs/ROADMAP.md` | вехи с критериями «готово» | чекбоксы; новая веха — через DECISIONS |
| `docs/STATE.md` | состояние, блокеры, 3 следующих шага | **перезаписывается** по шаблону внутри |
| `docs/DECISIONS.md` | решения (ADR-lite) | **только дописывать**; отменённое — `Superseded by D-xxx` |
| `docs/REFERENCES.md` | источники и факты со статусом проверки | дописывать, **перечитав конец файла**: номер — следующий S-xx после последнего; статус факта обновлять |
| `docs/IDEAS.md` | всё вне текущей вехи | дописывать |
| `docs/handoff/` | итог сессии | новый файл на сессию |

Историческое утверждение и размер — со ссылкой S-xx в REFERENCES или с пометкой «гипотеза» (D-020).

**Фото на Google и Яндекс Картах** (владелец, 2026-09-27) — смотреть в браузере, чтобы поправить формы и материалы; файлы не сохранять и в git не класть, выкачку скриптом не делать. В REFERENCES — ссылка на место и вывод (размер, цвет, деталь) со статусом «по фото на картах». Хранимые референсы — только Commons с манифестом и фото владельца.

## Конец сессии (`/handoff`)

1. `docs/handoff/YYYY-MM-DD_NN_<тема>.md` (NN — номер сессии за день): «Что сделали», «Что узнали», «Не проверено», «Где остановились», «Следующая сессия — фокус».
2. `docs/STATE.md` перезаписан: «Обновлено» — сегодня, один экран.
3. Выполненное отмечено в `docs/ROADMAP.md`.
4. Решения, факты и идеи — в свои файлы по таблице выше.
5. Кадр «было / стало» — `media/progress/YYYY-MM-DD_<что>.jpg`.
6. Коммит `<веха или область>: <что сделано>`; `Co-Authored-By` — модель, которая делала работу. Когда параллельно работают другие агенты, `git add` — явными путями своих файлов: редактор сохраняет и чужие пакеты.

Готово, когда в `git status` не осталось твоих незакоммиченных файлов.

## Репозиторий

```
docs\             GOALS, ROADMAP, STATE, DECISIONS, REFERENCES, IDEAS, handoff\
scripts\          скрипты редактора и офлайн (.venv), blender\ — генераторы героев; каталог — scripts\README.md
refs\             исходные данные: OSM, DEM, фото (LFS)
build\            выгрузки скриптов, пересобираются (вне git)
media\progress\   кадры и ролики для истории (LFS)
web\              просмотрщик веб-версии; сцену в build\web\ собирает scripts\web_export.py
Krom\             UE-проект
.githooks\        хуки git: pre-commit — scripts\check_text.py (управляющие символы, битый UTF-8)
```

Сгенерированные ассеты UE не в git (D-045): свежий клон собирается по `scripts/README.md` «Первичная сборка».

## Соглашения

- **Масштаб и оси:** реальные размеры, 1 uu = 1 см (в коде — метры). Z — вверх, X — на север, Y — на восток; начало — центроид Троицкого собора, Z = 0 — земля у собора (D-013, D-014).
- **Повторяемое — скриптом** в `scripts/`: идемпотентным, акторы с тегом `generated:<script>` (README «Соглашения»). Префиксы ассетов: `SM_`, `M_`, `MI_`, `T_`, `BP_`, `L_`, `SEQ_`.
- **Бюджет — 6 ГБ видеопамяти** (RTX 3060 Laptop): Lumen software, Nanite, без Hardware RT; текстуры до 2K, 4K — героям.
- **Правки Python** — инструментами Edit/Write: heredoc портит `\n` и пути Windows в строках.
- **Документы для агентов** (этот файл, README, планы, промпты субагентам) — по skill `/writing-for-agents`: одна мысль в одном месте, указатели с триггерным словом впереди, шаги с критерием готовности.

## Редактор и Blender

- **Редактор UE** — `python scripts/ue_run.py scripts/<x>.py` или `-c "<код>"` (Python Remote Execution, D-011); при запущенном процессе рендера `ue_run` сам выбирает редактор.
- **Без Python API** (создание Landscape и т. п.) — интерфейс редактора через SlateInspector встроенного MCP, когда он подключён (D-010, D-015): процедура — `scripts/README.md` «Landscape»; новую процедуру записать туда же. Клики в редакторе и работу в Blender делает агент, владелец смотрит результат.
- **Облачная сессия** (Cowork) — планирование, разведка и документы: Remote Execution и MCP слушают только 127.0.0.1, редактором управляет агент, запущенный на ноутбуке из `D:\PskovKrom`.
- **«Шашечка»** — материал не скомпилирован: после скриптов с материалами искать `Failed to compile Material` в `Krom.log`.
- **Blender** — `python scripts/bl_run.py scripts/blender/<x>.py` (D-018), выгрузки в `build/`.

## Агенты

- **Субагенты** — на Opus 5.5 (`model: "opus"`); Fable — когда задача правда требует, с причиной для владельца.
- **Продолжение** остановленного субагента — новым агентом с путями к наработкам: возобновлённый через SendMessage работает на модели родителя.
- **Субагент делает работу сам**, без своих субагентов.
- **Картинки** — уменьшенной копией JPG или кропом: полноразмерные PNG раздувают контекст и рвут соединение (ECONNRESET).
- **Внешние запросы** — User-Agent `PskovKrom/0.1 (scripts/…)`; e-mail и имя владельца остаются вне запросов, а если сервис требует контакт — спросить владельца.
