# Handoff 2026-09-25 #05 — M2 закрыта: blockout Крома, камеры, фото-референсы Commons

## Что сделали
- **Башни.** В OSM башни Крома не размечены, а в выгрузке S-02 нет ни одного узла. Центры взяты по петлям, которыми линии стен OSM обходят башни по внешней грани. Точки Wikidata (S-20) отстоят от них на 4–9 м. Сверка — спутник Esri (S-21, только глазами) и точки OSM (S-22, `refs/osm/krom_points_2026-09-25.json`).
- **Колокольня** стоит в восточной стене: линия OSM обходит её четырёхугольником 12,5 × 14,3 м. ГИКЭ (S-23) подтверждает место: 92 м по стене от Средней, у нас 91 м.
- **Скрипты:**
  - `krom_plan.py` (без `unreal`) — единственное место с положениями и размерами. Здания заданы как `Building` / `Part`, стены — как `WallRun` «башня — башня». Самопроверка: `python scripts/krom_plan.py`.
  - `blockout_krom.py` — ≈380 примитивов из `/Engine/BasicShapes` плюс граненые `SM_BO_Pyramid4 / Prism8 / Pyramid8` (GeometryScript) и `M_Blockout` + `MI_BO_*`. Высоты берутся трассировкой по Landscape. Стены западная и восточная 8,4 м (с кровлей, S-23).
  - `cameras_krom.py` — `CAM_Zavelichye` (у Ольгина креста, на бровке), `CAM_OlginskyBridge`, `CAM_PskovaMouth`.
  - `shot_krom.py` — PNG через SceneCapture2D; `shot_photos()` — модель с точек съёмки фото.
  - `photo_refs.py` — 11 фото Commons со свободными лицензиями и манифест (D-017); `compare` склеивает пары «фото | модель».
- **Баг M1 починен:** у воды оставалась коллизия BlockAll, потому что `set_collision_enabled` в редакторе не сохраняется. Теперь `set_collision_profile_name("NoCollision")` в `landscape_krom.py`.

## Что узнали
- Высота собора: 60 м до яблока (S-06) и 63 м общая (S-24). Замер по фото при яблоке 60 м даёт крест ≈63 м. Цифры 72/78 м (sobory.ru, Википедия) не подтверждаются. Главы: центральная золочёная, четыре тёмные, плюс главы приделов.
- Смердья = Довмонтова: восьмигранная 6,67 × 6,55 м, 22/26 м. Её построил не Тон (как в Википедии), а губернский архитектор Ранвид, 1862–1866.
- По фото стены бежевые (открытый плитняк) под серой тёсовой кровлей, шатры серые, у Кутекромы и Высокой сторожевые вышки. Раздел «Цвета и материалы по фото» в REFERENCES — это вход для M4.
- UE 5.8 из Python:
  - `HighResShot` / `take_high_res_screenshot` в фоне файл не пишут: вьюпорт не перерисовывается. SceneCapture работает синхронно, но без Lumen: тени чёрные, небо не подсвечивает.
  - `unreal.EditorPerformanceSettings` недоступен.
  - Python редактора кеширует модули между запусками `ue_run.py`, поэтому нужен `importlib.reload`.
  - `create_new_static_mesh_asset_from_mesh` лежит в `GeometryScript_NewAssetUtils`, а не в `AssetUtils`.
- Commons: у 550 из 1289 файлов категории Кремля есть camera location. У десятков координаты-заглушка (−316, 230) — их не брать. API Википедии ограничивает частоту запросов: нужны паузы и User-Agent. Overpass без User-Agent отвечает 406.
- Агент-исследователь поставил в пользовательский Python пакет `pymupdf` (для чтения сканов PDF).
