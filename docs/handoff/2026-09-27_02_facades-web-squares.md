## Что узнали
- **Возобновлённый субагент наследует модель родителя** (Fable) — вместо `SendMessage` на остановленного агента спавнить нового на Opus с указанием папок с наработками. Вложенные субагенты (агент плодит разведчиков) — запрещать в промпте.
- **Удаление всех акторов папки + повторное создание в том же прогоне** роняет UE 5.8 (`ActorFolder.cpp:228`). Переиспользовать акторы, перезаписывать ассеты.
- **Превью — только в отдельном процессе**; статус MRQ (`is_rendering`) за него не отвечает, ждать выхода `UnrealEditor-Cmd.exe`.
- Оси three.js: (x, y, z) = (X, Z, Y) проекта, `rotation.y = −yaw` — совпадает с экспортом Blender.
- В Python-патчах через heredoc следить за `\n` внутри строк с `\\` — один раз в файл попал литерал `\n`.
