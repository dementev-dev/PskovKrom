## Что узнали
- **Материал, который не компилируется, рисуется «шашечкой»** — ловится только по `Krom.log` (`Failed to compile Material`), скрипты этого не видят. Проверять лог после каждого `*_krom.py` с материалами.
- **Возобновление субагента = модель родителя.** Проверка: `grep -o '"model":"claude-[a-z0-9-]*' <transcript>`.
- **Вложенные субагенты** (агент плодит своих разведчиков и отдаёт ход, не дождавшись) — теряют время; в промптах: «no subagents, do the work yourself».
- **Сеть упала ночью** — процесс оркестратора перезапустился, редактор завис (счётчик кадров в логе стоял). Ночные скрипты сохраняют пакеты в конце, потерь не было.
- **Обрывы API (ECONNRESET)** чаще у агентов с большим контекстом картинок — в промптах: смотреть картинки уменьшенными.

- Плотина: устои и бьеф — по фото; дно долины парка опущено (гипотеза). Восточная половина парка и западная треть кладбища — за краем Landscape.
