## Что узнали
- Встроенный MCP работает в режиме tool search: в `tools/list` три мета-инструмента, остальное доступно через `describe_toolset` + `call_tool`.
- `ProgrammaticToolset` — песочница без `import unreal`, поэтому генераторы запускаются через `ue_run.py`, а не через MCP.
- `CaptureViewport` требует `annotations`. Без разметки: `gridSpacing=0, maxLabelDistance=0, maxLabels=0`, `classFilter` всё равно передать.
- В шаблонном `Lvl_FirstPerson` начало координат закрыто блоком `SM_Cube13` (7×4×2 м). Для кадра шаблонные меши временно скрывались в редакторе, тестовые акторы потом удалены. Уровень шаблона не сохраняли.
- Python в Windows (Store 3.13) не понимает пути `/tmp` из Git Bash: временные файлы класть в `$TEMP`.
